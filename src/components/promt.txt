## 4. Sidebar — Mandatory Requirement

The sidebar must be implemented in a **dedicated, reusable component file** named `Sidebar.jsx`, with its own stylesheet in `Sidebar.css`.

Do not write the sidebar markup repeatedly in every page.

Requirements:

- Follow the sidebar design shown in the reference screenshot.
- Use the same blue color palette, logo placement, navigation spacing, and typography.
- Include the appropriate menu items and icons based on the screenshot.
- Highlight the active menu based on the current route.
- Support navigation using React Router DOM.
- Group menu items logically if the screenshot indicates menu sections.
- Keep the sidebar consistent across all authenticated application pages.
- Allow future menu items to be added or removed easily.
- Keep the sidebar independent of individual page content.
- Use reusable configuration data for menu labels, routes, and icons.
- Ensure the sidebar does not overlap or obscure the main content.
- Support responsive behavior on smaller screens.

Example implementation approach:

```jsx
// components/layout/Sidebar.jsx

import { NavLink } from "react-router-dom";
import {
  LayoutDashboard,
  Users,
  Package,
  Tags,
  Wrench,
  ClipboardList,
  FileText,
  UserCircle,
} from "lucide-react";
import "./Sidebar.css";

const menuItems = [
  {
    label: "Dashboard",
    path: "/dashboard",
    icon: LayoutDashboard,
  },
  {
    label: "Data Pengguna",
    path: "/users",
    icon: Users,
  },
  {
    label: "Kategori Barang",
    path: "/categories",
    icon: Tags,
  },
  {
    label: "Inventaris & Stok",
    path: "/inventory",
    icon: Package,
  },
  {
    label: "Jasa Servis",
    path: "/services",
    icon: Wrench,
  },
  {
    label: "Transaksi",
    path: "/transactions",
    icon: ClipboardList,
  },
  {
    label: "Laporan",
    path: "/reports",
    icon: FileText,
  },
  {
    label: "Profil Saya",
    path: "/profile",
    icon: UserCircle,
  },
];

export default function Sidebar() {
  return (
    <aside className="sidebar">
      {/* Add logo and application branding here */}

      <nav className="sidebar-nav">
        {menuItems.map(({ label, path, icon: Icon }) => (
          <NavLink
            key={path}
            to={path}
            className={({ isActive }) =>
              `sidebar-link ${isActive ? "active" : ""}`
            }
          >
            <Icon size={18} />
            <span>{label}</span>
          </NavLink>
        ))}
      </nav>
    </aside>
  );
}
```

Treat this code as a starting point, not a requirement to use the exact labels or menu items. Adjust the menu according to the screenshot and the existing application requirements.

## 5. Shared Dashboard Layout

Create a reusable `DashboardLayout.jsx` component that imports and renders the sidebar, header, and page content.

Example:

```jsx
import Sidebar from "./Sidebar";
import Header from "./Header";

export default function DashboardLayout({ children }) {
  return (
    <div className="dashboard-layout">
      <Sidebar />

      <div className="dashboard-main">
        <Header />

        <main className="dashboard-content">
          {children}
        </main>
      </div>
    </div>
  );
}
```

All authenticated pages must reuse this layout.

The login page should have its own layout without the dashboard sidebar.

## 6. Design System

Follow the reference screenshot as closely as possible.

### Colors
- Primary blue: use a color close to `#00699B` or the closest matching blue in the reference.
- Active navigation: use a contrasting blue or lighter blue background, based on the screenshot.
- Main background: light gray or off-white.
- Content surfaces: white.
- Primary actions: blue.
- Destructive actions: red.
- Success states: green.
- Warning states: yellow or amber.
- Text: dark gray or near-black.
- Borders: subtle light gray.

Adjust the color values after inspecting the screenshot.

### Layout
- Keep a fixed-width or appropriately responsive sidebar on desktop.
- Let the main content occupy the remaining available width.
- Use consistent page padding and spacing.
- Align cards, tables, and form containers properly.
- Use subtle borders, small corner radii, and restrained shadows.
- Maintain a clean administrative dashboard appearance.

### Typography
- Use a consistent, readable sans-serif font.
- Reproduce the hierarchy between page titles, section headings, labels, and supporting text.
- Keep font sizes and font weights consistent across pages.

### Reference Fidelity
Do not introduce a completely different visual style.
Avoid unnecessary gradients, oversized cards, excessive rounded corners, excessive whitespace, or decorative elements that do not exist in the reference.
